# YOBA SFML full example

Since `YOBA` is hardware-independent, I thought it would be fun to add support for running it on Windows and Linux.
And [SFML](https://github.com/sfml/sfml) is perfect for such shit! Just clone this repo and have fun in your favourite IDE.
